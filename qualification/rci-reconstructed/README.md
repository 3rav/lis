# Temporary native LIS qualification

Independent reconstructed real-double RCI; NOT the original RC3. No MPI. No private matrices or production solver changes. Smoke input archive SHA-256: 95fdea9d68dbf892b98878518ac61e5ae5b39d75bad72941120ab6402a413425.

Native tests cover serial/OpenMP (1/4 threads), 32/64-bit indices with a runtime ABI check, and four RCI methods. BCSSTK01 is the public 48x48 structural engineering test matrix HB/bcsstk01 (400 entries after expansion). Numeric data copied from https://github.com/CSCsw/ColPack/blob/master/Graphs/bcsstk01.mtx (Git blob 2a454abbb2ede2f0283ab79398ca3b5b3da11362). Matrix metadata: https://sparse.tamu.edu/HB/bcsstk01 and https://math.nist.gov/MatrixMarket/data/Harwell-Boeing/bcsstruc1/bcsstk01.html. The right-hand sides are generated from independent known solutions; RCI/LIS solves are checked against independent dense arithmetic. A synthetic 8192-dimensional CSR case exercises actual OpenMP teams and RCI parallel loops. These tests are limited evidence; no broad industrial or official ABI/release claim.
