# Experimental Generic RCI in LIS (reconstruction)

The independent real-double reconstruction is now available as an optional Autotools feature on this qualification branch. This is not the original RC3. Build using `./configure --enable-rci --disable-mpi --disable-complex --disable-longdouble --disable-quad`; OpenMP and longlong are optional. Default disabled. Existing solver dispatch and structures are not changed. The installed public headers are lis_rci.h and lis_rci_bridge.h. Symbols use the lis_rci_ prefix; this is a new API baseline, not RC2/RC3 compatibility. Before typed LIS calls, use the ABI-stable LIS_RCI_CHECK_CLIENT_ABI() check and compile against the generated lis_config.h with matching flags (including -D_LONG__LONG for 64-bit LIS). The bridge borrows an assembled matrix; caller must retain its lifetime and not mutate it during a solve. The generic core requires a fixed linear preconditioner for CG/BiCGSTAB/GMRES; FGMRES permits varying preconditioner. CG requires SPD. No MPI, complex, long double or quad solver qualification. No merge, tag, or production release. Previous smoke archive and tests are retained as qualification evidence. Integrated tests link installed liblis.so rather than extra solver objects. Full library ASan/UBSan tests and default-disabled checks are included.
